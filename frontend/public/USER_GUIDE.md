## 시작하기

VirtualScenario는 코레일 안전교육 시나리오를 제작할 수 있는 3D 에디터입니다.

### 주요 기능
- ✅ **3D 씬 편집**: Three.js 기반 실시간 3D 뷰어
- ✅ **배경 맵 시스템**: 재사용 가능한 배경 환경 (승강장, 선로 등)
- ✅ **오브젝트 관리**: 프리미티브 & 3D 모델 지원
- ✅ **애니메이션**: 키프레임 기반 Path 애니메이션
- ✅ **대화/자막 시스템**: 시간 기반 자막 표시
- ✅ **시뮬레이터**: 완성된 시나리오 재생 및 미리보기

## 프로젝트 관리

### 새 프로젝트 만들기
1. 대시보드 상단의 **"새 프로젝트 만들기"** 버튼 클릭
2. 프로젝트 제목, 설명, 버전 입력
3. **"생성"** 버튼 클릭

### 프로젝트 열기
- 대시보드에서 프로젝트 카드 클릭 또는 **"✏️ 편집"** 버튼 클릭

### 프로젝트 재생
- 프로젝트 카드의 **"▶️ 재생"** 버튼 클릭하여 시뮬레이터 실행

### 프로젝트 삭제
- 프로젝트 카드의 **"🗑️ 삭제"** 버튼 클릭 (복구 불가능)

## 씬 편집

### 씬 생성
1. 프로젝트 열기
2. 좌측 패널에서 **"씬 추가"** 버튼 클릭
3. 씬 제목, 설명, 참여 인원 입력

### 배경 설정
1. **"배경 설정"** 탭 선택
2. 드롭다운에서 배경 맵 선택 (승강장, 선로, 열차 내부 등)
3. 선택한 배경의 오브젝트가 3D 뷰에 자동 표시됨

### 오브젝트 추가
1. **"오브젝트"** 탭 선택
2. **"오브젝트 추가"** 버튼 클릭
3. 에셋 라이브러리에서 원하는 오브젝트 선택
   - **프리미티브**: 사각형, 구, 원기둥, 원뿔, 평면, 도넛
   - **3D 모델**: 업로드한 GLB/GLTF/OBJ/FBX 파일
   - **이미지**: PNG/JPG 파일
   - **텍스트**: 3D 텍스트

### 오브젝트 편집
1. 3D 뷰에서 오브젝트 클릭하여 선택
2. Gizmo를 드래그하여 위치/회전/스케일 조정
3. 우측 Inspector 패널에서 세부 설정:
   - **이름**: 오브젝트 이름 변경
   - **색상**: HEX 색상 코드 입력 (프리미티브만 해당)
   - **Transform**: 위치(X, Y, Z), 회전(X, Y, Z), 크기(X, Y, Z)
   - **네임태그 표시**: 3D 뷰에 오브젝트 이름 표시
   - **보이기**: 오브젝트 가시성 토글
   - **잠금**: 선택 불가능하게 잠금

### Gizmo 모드 전환
- **W 키**: 이동(Translate) 모드
- **E 키**: 회전(Rotate) 모드
- **R 키**: 크기(Scale) 모드

### 키프레임 애니메이션
1. 오브젝트 선택 후 원하는 위치/회전/크기로 변경
2. **K 키** 또는 타임라인의 **"+ 키프레임"** 버튼 클릭
3. 타임라인에서 시간 이동 후 다시 키프레임 추가
4. 재생 시 자동으로 보간되어 부드럽게 이동

### 대화/자막 추가
1. **"대화"** 탭 선택
2. **"대화 추가"** 버튼 클릭
3. 입력 내용:
   - **발화자**: 오브젝트 선택 (선택사항)
   - **대사**: 자막 텍스트
   - **시작 시간**: 대화가 시작되는 시간 (초)
   - **지속 시간**: 자막이 표시되는 시간 (초)

## 배경 맵 관리

### 새 배경 맵 만들기
1. 대시보드에서 **"배경 맵 관리"** 버튼 클릭
2. **"새 배경 맵 만들기"** 버튼 클릭
3. 이름, 설명, 아이콘 입력
4. 그리드 크기 설정 (기본: 20x20)

### 배경 오브젝트 추가
1. 배경 맵 선택
2. **"오브젝트 추가"** 버튼으로 바닥, 벽, 기둥 등 추가
3. 여러 씬에서 동일한 배경 재사용 가능

### 배경 맵 활용
- **승강장**: 노란 안전선, 플랫폼, 대기 공간
- **선로**: 기차 선로, 신호등
- **열차 내부**: 좌석, 손잡이, 출입문
- **역사**: 매표소, 안내판, 대합실
- **빈 공간**: 배경 없이 자유롭게 구성

## 에셋 라이브러리

### 3D 모델 업로드
1. 대시보드에서 **"에셋 라이브러리"** 버튼 클릭
2. **"모델 업로드"** 버튼 클릭
3. 지원 형식: **GLB, GLTF, OBJ, FBX** (최대 500MB)
4. 이름과 카테고리 입력 후 업로드

### 이미지 업로드
1. **"이미지 업로드"** 버튼 클릭
2. 지원 형식: **PNG, JPG, JPEG** (최대 10MB)
3. 표지판, 안내문 등으로 활용 가능

### 텍스트 에셋 생성
1. **"텍스트 추가"** 버튼 클릭
2. 텍스트 내용, 폰트 크기, 색상 설정
3. 3D 씬에 텍스트 레이블로 표시됨

### 에셋 삭제
- 에셋 우클릭 → **"삭제"** 선택
- 프리미티브는 삭제 불가 (시스템 기본 제공)

## 시뮬레이터

### 시나리오 재생
1. 대시보드에서 프로젝트 선택 후 **"▶️ 재생"** 버튼
2. 또는 씬 편집 화면에서 **"시뮬레이터"** 버튼 클릭

### 재생 컨트롤
- **▶️ 재생**: 시뮬레이션 시작
- **⏸️ 일시정지**: 재생 일시 중지
- **⏹️ 정지**: 재생 중지 및 첫 씬으로 이동
- **⏮️ 이전 / ⏭️ 다음**: 씬 전환
- **타임라인 슬라이더**: 드래그하여 원하는 시간으로 이동
- **속도 조절**: 0.5배속, 1배속, 2배속

### 자막 시스템
- 대화 시작 시간에 맞춰 자동으로 표시
- 화면 하단에 발화자 이름 포함
- Fade-in 애니메이션 효과

### 영상 내보내기 (MP4)
1. Electron 앱에서 시뮬레이터 실행 (`npm run electron` 또는 패키지)
2. 우측 상단 **"📹 MP4 내보내기"** 클릭 → 캔버스/모델 로드 후 자동 녹화
3. 시나리오가 끝까지 재생되면 저장 위치 선택 → WebM→MP4 변환 완료
- 브라우저 개발 서버에서는 MP4 내보내기를 지원하지 않습니다.

## 단축키

### 전역 단축키
- **Ctrl + Z** (Mac: Cmd + Z): 실행 취소
- **Ctrl + Shift + Z** (Mac: Cmd + Shift + Z): 다시 실행

### 3D 뷰 단축키
- **W**: 이동(Translate) 모드
- **E**: 회전(Rotate) 모드
- **R**: 크기(Scale) 모드
- **K**: 현재 Transform 키프레임 추가
- **Delete**: 선택한 오브젝트 삭제
- **마우스 휠**: 줌 인/아웃
- **우클릭 드래그**: 카메라 회전
- **중간 버튼 드래그**: 카메라 팬

### 타임라인 단축키
- **Space**: 재생/일시정지
- **Home**: 타임라인 처음으로 이동
- **End**: 타임라인 끝으로 이동

## Undo/Redo 시스템

### 지원 작업
- ✅ Transform 변경 (위치, 회전, 스케일)
- ✅ 오브젝트 생성
- ✅ 오브젝트 삭제
- ✅ 키프레임 추가/삭제

### 사용 방법
- **Ctrl+Z**: 마지막 작업 취소
- **Ctrl+Shift+Z**: 취소한 작업 다시 실행
- 또는 좌측 상단 **"실행 취소 / 다시 실행"** 버튼 클릭

### 제한사항
- 최대 50개 작업 기록
- 오브젝트 삭제 후 복원 시 새 ID로 생성됨 (이름에 "(복원됨)" 표시)

## 팁 & 주의사항

### 성능 최적화
- 씬당 오브젝트 수를 50개 이하로 유지
- 대용량 3D 모델은 LOD(Level of Detail) 적용 권장
- 불필요한 오브젝트는 "보이기" 체크 해제

### 재생 중 편집 방지
- 시뮬레이터 재생 중에는 씬 편집 불가
- 편집하려면 재생을 중지해야 함

### 장면 길이 조절
- 타임라인 패널에서 숫자 입력으로 수동 조절 (10-600초)
- 기본값: 마지막 대화 종료 시간 + 2초 (최소 10초)

### 네임태그 활용
- 복잡한 씬에서 오브젝트 식별에 유용
- 네임태그 표시를 끄면 3D 뷰가 깔끔해짐

### 배경 맵 재사용
- 자주 사용하는 환경은 배경 맵으로 저장
- 동일한 배경을 여러 씬에서 일관되게 사용 가능

## 문제 해결

### 모델이 로드되지 않을 때
- 에셋 라이브러리에서 해당 에셋이 존재하는지 확인
- 파일이 삭제된 경우 빨간색 경고와 함께 기본 박스로 표시됨
- 다시 업로드하거나 다른 에셋으로 교체

### 에셋 이름 변경 오류
- 이름에 특수문자나 이모지 사용 시 오류 발생 가능
- 영문, 한글, 숫자만 사용 권장

### 키프레임이 적용되지 않을 때
- 오브젝트 선택 후 K 키를 눌렀는지 확인
- Inspector 패널의 키프레임 목록에서 추가 여부 확인
- 재생 중에는 키프레임 추가 불가
