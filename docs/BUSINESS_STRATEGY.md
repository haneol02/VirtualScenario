### 2.2 기능·성능의 차별성 및 경쟁력

#### 핵심 차별화 기능

| 기능 | 설명 | 경쟁 우위 | 기술 스택 |
|------|------|-----------|-----------|
| **철도 특화 배경 맵** | 승강장, 선로, 역사 등 사전 제작 환경 | 경쟁사는 범용 템플릿만 제공 | Three.js Custom Scenes |
| **키프레임 애니메이션** | 타임라인 기반 오브젝트 이동 경로 설정 | 직관적 UI로 비전문가도 사용 가능 | RAF + Lerp/Slerp 보간 |
| **실시간 3D 시뮬레이터** | 웹/데스크톱에서 즉시 재생 | Unity는 별도 빌드 필요 | React Three Fiber |
| **다목적 Export** | MP4 영상 + Excel 문서 + JSON 데이터 | 한 번 작업으로 3가지 결과물 | ffmpeg + ExcelJS |
| **오프라인 우선** | 인터넷 없이 완전 작동 | 교육 현장은 보안상 망분리 환경 | Electron + SQLite |
| **저비용 운영** | 오픈소스 기반으로 라이선스 비용 無 | 초기 투자 1/10 수준 | Node.js, React |

### 2.3 경쟁력 확보 전략

#### 2.3.1 기술 경쟁력

**특허 출원 계획**:
1. **키프레임 기반 3D 시나리오 편집 시스템** (2025년 6월 출원)
   - 타임라인 + Transform 통합 UI
   - Undo/Redo 히스토리 관리 알고리즘

2. **철도 안전교육 시나리오 자동 생성 방법** (2026년 예정)
   - AI 기반 시나리오 템플릿 추천
   - 대화 스크립트 자동 완성

**오픈소스 기여**:
- React Three Fiber 커뮤니티 활동 (GitHub 스타 50+)
- Three.js 한글 문서 번역 참여
- 기술 블로그 운영 (월 2회 포스팅)

#### 2.3.2 품질 경쟁력

**테스트 전략**:
- **단위 테스트**: Jest + React Testing Library (커버리지 80% 이상)
- **E2E 테스트**: Playwright (핵심 시나리오 20개)
- **성능 테스트**: Lighthouse CI (Performance 90점 이상)
- **보안 테스트**: OWASP Top 10 취약점 점검 (분기별)

**품질 인증 계획**:
- 2026년: GS 인증 1등급 (소프트웨어 품질)
- 2027년: ISO 9001 (품질경영시스템)
- 2027년: ISO 27001 (정보보호)

#### 2.3.3 고객 경쟁력

**사용자 경험 차별화**:
- **1분 튜토리얼**: 첫 시나리오 완성까지 1분 가이드
- **템플릿 라이브러리**: 20종 사전 제작 시나리오 제공
- **실시간 지원**: 채팅 상담 (평일 9-18시)
- **커뮤니티**: 사용자 포럼 운영 (Q&A, 노하우 공유)

**고객 락인(Lock-in) 전략**:
- 무료 플랜으로 진입장벽 제거
- 클라우드 백업으로 데이터 종속성 강화
- 네트워크 효과 (다른 기관 사례 공유)

| **다목적 Export** | MP4 영상, Excel 문서, JSON 데이터 → 활용도 극대화 |

### 3.3 경쟁사 분석

| 구분 | VirtualScenario (당사) | Unity VR (글로벌) | Articulate (글로벌) |
|------|------------------------|-------------------|---------------------|
| 타겟 | 철도/교통 산업 | 제조/의료/국방 | 일반 기업 교육 |

**결론**: VirtualScenario는 **국내 철도 산업에 특화된 저비용 솔루션**으로 틈새시장을 공략

### 8.1 환경 (Environment)

#### 8.1.1 폐기물 감소 및 친환경 운영
- **종이 교육자료 대체**: VirtualScenario 도입으로 연간 종이 사용량 90% 감소
  - 예) 코레일 1개 본부 기준: 연 10,000장 → 1,000장 (9,000장 절감)
- **재활용 확대**: 퇴직한 교육 장비(VR 헤드셋, PC)를 지역아동센터에 기부
- **친환경 서버**: AWS 재생에너지 리전 사용 (Seoul 리전: 태양광 발전 비율 30%)
- **탄소중립 목표**: 2030년까지 Scope 1/2 배출 제로 (전기차 업무용 차량 도입)

#### 8.1.2 에너지 절감
- **경량 아키텍처**: Three.js 기반 렌더링으로 GPU 전력 소비 50% 감소 (vs Unity)
- **오프라인 우선**: Electron 앱으로 네트워크 트래픽 최소화 → 데이터센터 전력 절감
- **에너지 효율 인증**: 2026년 ENERGY STAR 인증 획득 목표

**정량 목표**:
- 2025: 고객사 1곳당 연간 탄소 배출 1톤 감소
- 2027: 누적 탄소 감축량 100톤 달성
- 2030: 탄소중립 인증 (CDP A등급)

### 8.2 사회 (Social)

#### 8.2.1 지역사회 교류 및 사회 환원
- **부산 지역 고용**: 개발자의 80%를 부산/경남 출신으로 채용 → 지역 인재 유출 방지
- **교육 기부**: 동아대, 부산대 학생에게 무료 워크숍 연 4회 개최
- **재능 기부**: 지역 사회복지관에 VR 안전교육 콘텐츠 무상 제공 (연 10개관)

#### 8.2.2 인권, 평등, 다양성 존중
- **장애인 채용**: 전체 인력의 5% 이상 장애인 고용 (장애인고용촉진법 준수)
- **성별 다양성**: 여성 개발자 비율 40% 이상 유지 (ICT 업계 평균 20% 상회)
- **다문화 지원**: 외국인 근로자에게 한국어 교육 지원 (주 2회)
- **근로자 인권**: UN 기업과 인권 이행원칙(UNGPs) 준수 선언

#### 8.2.3 직원 복지 및 성장 지원
- **워라밸**: 주 4.5일 근무제 (금요일 오후 자율출근)
- **교육 지원**: 연 200만원 교육비 지원 (Udemy, 컨퍼런스 등)
- **건강 관리**: 연 1회 종합건강검진, 심리 상담 무료 제공
- **육아 지원**: 육아휴직 급여 100% 지급 (법정 80% 초과)

**정량 목표**:
- 2025: 지역 청년 일자리 3개 창출
- 2027: 사회 공헌 활동 시간 1,000시간 달성
- 2030: B Corp 인증 획득 (사회적 기업)

### 8.3 지배구조 (Governance)

#### 8.3.1 윤리경영
- **윤리 헌장**: 창립 시점부터 '반부패, 공정거래, 정보보호' 3대 원칙 수립
- **내부 고발 제도**: 익명 제보 채널 운영 (외부 변호사 직접 수령)
- **뇌물 금지**: 공공기관 입찰 시 '청렴 서약서' 자발적 제출
- **ESG 위원회**: 이사회 내 ESG 전담 위원회 구성 (외부 전문가 포함)

#### 8.3.2 상호 존중 조직문화
- **수평적 소통**: 모든 직원 영어 이름 호칭, 직급 폐지
- **의사결정 참여**: 주요 결정 사항 전 직원 투표제 (Holacracy 방식)
- **심리적 안전**: 분기별 익명 설문으로 조직문화 지수 측정 (목표 80점 이상)
- **반차별 정책**: 성별, 나이, 학력 차별 금지 명시화

#### 8.3.3 근로 환경 개선
- **재택근무**: 주 2일 재택 기본, 100% 원격 가능
- **근로시간 관리**: 야근 사전 승인제, 초과 근무 시 보상휴가 지급
- **사무 환경**: 1인당 업무 공간 3평 이상, 스탠딩 데스크 전 직원 제공
- **안전 보건**: 산업안전보건법 준수, 연 2회 안전 교육

#### 8.3.4 투명 경영
- **재무 공개**: 2026년부터 연간 재무제표 홈페이지 공개
- **주주 소통**: 분기별 IR 자료 발행, 주주총회 웹캐스팅
- **감사 제도**: Big4 회계법인 외부 감사 (2027년부터)
- **정보보호 인증**: ISO 27001, ISMS-P 인증 획득 (2026년)

**정량 목표**:
- 2025: 윤리경영 헌장 제정, 내부 고발 제도 구축
- 2027: ESG 평가 B등급 (한국기업지배구조원)
- 2030: ESG 평가 A등급, UN 글로벌 콤팩트 가입
